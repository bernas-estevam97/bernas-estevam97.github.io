I study motor behaviour in rodent models through kinematic analysis, and write the software that turns raw tracking and imaging data into reproducible results.

I am a PhD candidate in Biomedical Sciences at the Faculty of Medicine and Biomedical Sciences, University of Algarve. My background spans biomedical sciences, neuroscience and software engineering, and my doctoral work focuses on kinematic motor analysis, tracking algorithms, biomechanical modelling and machine learning.

Alongside the research, I develop open-source tools for gait analysis, calcium imaging and behavioural tracking, most of them built at the Algarve Biomedical Center to replace slow manual analysis steps.

I am currently focused on my doctoral research and am not looking for new positions. I welcome research collaborations, questions about my tools, and the occasional small side project.

Research interests

  • Animal tracking and computer vision

Research software

Tools and databases I have built for neuroscience and biomedical research. Source code is on GitHub unless noted.

PolyQ Database

Web & database

A Django web application backed by Microsoft SQL Server that hosts clinical and research data for the nine known polyglutamine neurodegenerative disorders, from molecular pathology to disease genetics.

  • Python/Django
  • MSSQL
  • JavaScript
polyq.pt

Mouseframe

Web application

Processes digitised images of rodent walking footprint patterns and extracts quantitative gait measurements for neuroscience and locomotion research.

  • Python/Django
  • JavaScript/Ajax
  • SQLite
  • reCAPTCHA v3
mouseframe.pt

Mouseframe Desktop

Desktop app

Cross-platform Electron counterpart to Mouseframe, letting researchers analyse digitised gait images offline with local caching and batch file import.

  • Electron
  • Node.js
  • JavaScript
Source code

Calcium Signal Peak Analyzer

Data analysis

Interactive application for baseline normalisation, peak detection, sub-sample kinetic parameter extraction and reporting of calcium imaging and fluorescence transients (F(t) and ΔF/F0).

  • Streamlit
  • SciPy
  • Savitzky–Golay
  • NumPy
  • Pandas
  • Vega-Altair
Source code

MotoRater Analysis Dashboard

Dashboard

Streamlit and Plotly platform for longitudinal behavioural and kinematic data from the MotoRater gait analysis apparatus, with statistical evaluation in Pingouin and Statsmodels.

  • Plotly

High-Throughput Data Treatment

Data pipeline

Data cleaning and ETL pipeline that uses Python-Calamine, Parquet columnar storage and multiprocessing to turn gigabytes of raw laboratory measurements into structured reports.

Faster, optimised version of the MotoRater data pipelines with a Flet desktop interface, using asyncio and threading for high-volume cleaning, Excel generation and schema conversion.
